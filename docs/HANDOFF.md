## 이 세션에서 데인 자리 (다음 세션이 또 밟지 않게)
<!-- keep:traps -->
**실제로 사고가 났던** 자리입니다. 자세한 건 `memory.md` 의 해당 판 항목.

| 함정 | 무엇 |
|---|---|
| **아틀라스 타일 번호는 남이 쓰고 있을 수 있다** | v92 가 새 묘목을 **담긴 양동이(81·82) 위에** 그렸습니다. 나중에 그린 쪽이 이기므로 묘목 그림이 소리 없이 지워졌는데, 시험은 "세 그림이 서로 다른가" 만 봐서 **통과했습니다**(양동이 두 개가 서로 다르니까). 이제 `paint()` 가 중복을 던지고, 시험이 **ALL_BLOCKS 의 타일이 실제로 그려진 것인지** 봅니다 |
| **`beginPlay()` 는 저장된 시점을 되살린다** | 시험이 `beginPlay` **앞에서** `player.yaw = 0` 을 넣어 두었더니 `S.savedYaw` 로 덮였습니다. `S.started` 가 이미 true 면 복원이 안 도니까 **단독 통과 · 전체 실패**가 됩니다 (v92) |
| **시험이 남기고 가는 상태는 언젠가 남이 본다** | `v10 3인칭` 이 `S.thirdPerson = 1` 인 채 끝나고 있었습니다(F5 를 네 번 눌러도 `(0+4)%3 = 1`). **3인칭에 볼 것이 생긴 판**(v92)에서야 드러났습니다. v94 시험이 동물을 1마리로 줄여 놓고 끝난 것도 같은 부류입니다(v13 이 간헐적으로 깨졌습니다) |
| **계기판은 `step` 이 아니라 `animate` 안에서 갱신된다** | `setPaused(true)` 로 재운 채 `step()` 만 돌리는 시험은 **화면 글자를 못 봅니다.** 실제 프레임을 돌려야 합니다 (v93) |
| **저장소가 이미 답을 갖고 있는 자리를 먼저 본다** | GPU 버퍼 누수는 `scene.js`·`hand.js` 가 **이미 dispose 하고 있었고** 수천 번 도는 `applyGeo` 만 빠져 있었습니다. 화각도 **바로 옆줄에서 손 카메라만** aspect 를 보고 있었습니다 (v93) |
| **남의 계측도 확인하고 쓴다** | 자문 19차의 "반쪽 문" 은 **`applyEdit` 을 직접 부른 계측**이었습니다 — 실제 좌클릭 경로(`mineAt`)는 v60 부터 두 칸을 묶어 지웁니다. 직접 재서 확인했습니다 |
| **빠르게 쓴 판은 스스로 되짚는다** | v84~v87 을 두 시간에 쓰고 `/code-review` 로 되짚었더니 **시험 332항목이 다 통과하는 채로 버그 여섯**이 나왔습니다(v88). 그중 하나는 **끝방이 통로 한가운데 생겨 버팀목·횃불을 지우고** 있었는데, 시험이 소품 **개수**만 세어 통과했습니다. **개수를 세는 시험은 "자리" 와 "순서" 를 못 잡습니다** — 자문을 기다리는 시간이 그 되짚기에 딱 맞습니다 |
