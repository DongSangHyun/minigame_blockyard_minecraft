## 이 세션에서 데인 자리 (다음 세션이 또 밟지 않게)
<!-- keep:traps -->
**실제로 사고가 났던** 자리입니다. 자세한 건 `memory.md` 의 해당 판 항목.

| 함정 | 무엇 |
|---|---|
| **`endBatch` 는 기록되는 편집마다 돈다** | `applyEdit` 이 단일 편집에도 제 묶음을 엽니다. v97 이 거기서 통계를 세게 했더니 **손으로 놓은 것이 두 번** 세어져 「100칸」이 50칸에 열렸고(문은 3배), **자란 나무·번진 불까지** 사람 것으로 쳤습니다. 그리고 v98 의 `liftIfBuried` 도 거기 걸려 **반블록 바닥에서 블록 하나만 놓아도 사람이 튀어 올랐습니다.** 여기에 무언가를 얹을 때는 **부르는 쪽이 시킬 때만** 돌게 하세요 (v99) |
| **`isSolid(get(...))` 는 모양을 못 본다** | 반블록·계단·카펫·눈 위에 선 것을 "묻혔다" 로 읽습니다. 몸이 겹쳤는지는 `boxHitsWorld`, 한 점은 `pointSolid` 입니다 (v99) |
| **세는 시험은 "세지 말아야 할 것" 부터 못 박는다** | `v22 우클릭` 이 10회 중 1회 깨졌는데, 앞 시험이 남긴 **눈**이 시험장에 쌓여 셈에 든 것이었습니다. 블록을 세는 시험은 `S.weather = 0` 을 먼저 박으세요 (v96) |
| **확률로 도는 것을 기다리지 않는다** | 불·성장·번식은 확률입니다 — "20초 안에 판자가 줄어든다" 는 10회 중 한 번 흔들립니다. **"판자가 줄었거나 불이 살아 있다"** 처럼 확률에 안 기대는 문장으로 (v99) |
| **하위 명령은 넓은 갈래보다 앞에** | `/marks del 1` 을 넣었는데 `cmd === "marks"` 목록 갈래가 먼저 걸려 목록만 찍었습니다 (v100) |
| **클라우드 세계 이름은 ASCII 만 남는다** | `normalizeName` 이 `[^a-z0-9_-]` 를 걸러서 **한글 이름은 통째로 "main"** 이 됩니다(gist 파일명이라 그렇습니다). UI 문구는 한국어인데 이 값만 다릅니다 (v100) |
| **아틀라스 타일 번호는 남이 쓰고 있을 수 있다** | v92 가 새 묘목을 **담긴 양동이(81·82) 위에** 그렸습니다. 나중에 그린 쪽이 이기므로 묘목 그림이 소리 없이 지워졌는데, 시험은 "세 그림이 서로 다른가" 만 봐서 **통과했습니다**(양동이 두 개가 서로 다르니까). 이제 `paint()` 가 중복을 던지고, 시험이 **ALL_BLOCKS 의 타일이 실제로 그려진 것인지** 봅니다 |
| **`beginPlay()` 는 저장된 시점을 되살린다** | 시험이 `beginPlay` **앞에서** `player.yaw = 0` 을 넣어 두었더니 `S.savedYaw` 로 덮였습니다. `S.started` 가 이미 true 면 복원이 안 도니까 **단독 통과 · 전체 실패**가 됩니다 (v92) |
| **시험이 남기고 가는 상태는 언젠가 남이 본다** | `v10 3인칭` 이 `S.thirdPerson = 1` 인 채 끝나고 있었습니다(F5 를 네 번 눌러도 `(0+4)%3 = 1`). **3인칭에 볼 것이 생긴 판**(v92)에서야 드러났습니다. v94 시험이 동물을 1마리로 줄여 놓고 끝난 것도 같은 부류입니다(v13 이 간헐적으로 깨졌습니다) |

| **저장소가 이미 답을 갖고 있는 자리를 먼저 본다** | GPU 버퍼 누수는 `scene.js`·`hand.js` 가 **이미 dispose 하고 있었고** 수천 번 도는 `applyGeo` 만 빠져 있었습니다. 화각도 **바로 옆줄에서 손 카메라만** aspect 를 보고 있었습니다 (v93) |
