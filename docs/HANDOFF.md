| 함정 | 무엇 |
|---|---|
| **한 축을 좁히면 반대쪽이 열린다** | v85 가 "나무 밑에서 지도가 꺼지는 것" 을 고쳤더니 v86 에서 **내가 판 굴에서 안 켜지는 것**이 드러났습니다. 두 경우 다 **가 본 적 없는 곳이 "밝혀짐" 으로 칠해졌습니다** — 지도 기억 오염은 되돌릴 길이 없습니다. 판정을 좁힐 때는 **반대 극단**을 같이 재세요 |
| **나눠서 고친 것은 경계에서 뭘 잃는지 본다** | v81 이 지하 지도를 세 겹으로 나눈 것은 옳았지만, **경계를 넘나드는 순간**(15걸음에 한 번)이 고친 문제보다 자주 눈에 띄었습니다(v83) |
| **큰 축을 옮기면 그 축을 *읽는* 곳을 전부 센다** | v79 가 해수면을 옮기며 import 25곳은 봤는데 **파생값**(수평선·구름·카메라·과제·소리·용암·광맥·새) 여덟 개를 놓쳤습니다 |
| **`export var` 라이브 바인딩은 세 자리에서 굳는다** | ① 최상위 상수 ② 훅 속성 ③ **오브젝트에 한 번 넣고 끝나는 곳**(`m.position.y = f()`). v79 가 ①②를 풀고 ③을 놓쳐 수평선이 12칸 어긋난 채 나갔습니다 |
| **인덱스 0 은 거짓이다** | `if (markHere())` 로 뒀더니 **첫 표식(0번)만** 이름이 안 붙었습니다. `x !== false`(v68)와 같은 부류 — **`>= 0` 으로 못 박으세요** |
| **"계획한 것" 과 "실제로 된 것"** | 끝방을 `lastLeg = (i === n-1)` 로 달았더니, 줄기가 중간에 끊기면 방이 영영 안 왔습니다(세계당 0~2개 · 기대 3개). 루프가 끊길 수 있으면 **성공한 마지막**을 들고 있어야 합니다 |

| **같은 부류를 새로 넣을 때는 기존 것과 성질을 통째로 견준다** | 색 카펫 16색을 원래 카펫과 전부 대조하는 시험이 **v74 의 구멍**(카펫이 바닥을 캐도 안 걷힘)을 잡았습니다 |
