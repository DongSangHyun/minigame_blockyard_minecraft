## 이 프로젝트에서 건드리지 말 것 (자문 의견)
마크보다 **오히려 나은** 부분입니다.
- 놓을 자리 고스트 프리뷰 — 마크엔 없음
- `Ctrl+Z` 240단계 되돌리기
- 지형 생성 시점에 모래/자갈 침강을 미리 처리 (동굴 천장에 뜬 모래가 없음)
- `G` 하나로 풀블록/반블록/계단 전환
- 지하에서 미니맵이 자동으로 단면도로 전환
