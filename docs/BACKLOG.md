| 항목 | 내용 | 난이도 |

| **바이옴 균형** | 바이옴 노이즈 임계값(`t < 0.36`)이 설원을 너무 많이 만든다. 시드 5개 중 3개가 육지의 70%가 설원 — 풀·꽃을 넣어도 안 보이는 세계가 나온다 | 하 (임계값 조정 + 시드별 실측 필요) |

| **모듈 분리** | 게임 코드를 ES 모듈로 나누는 작업 (사용자 승인) | 진행 중 |

- 놓을 자리 고스트 미리보기 · `Ctrl+Z` 240단계 되돌리기
